กำลังโหลดข้อมูลเส้นทาง (way)...

กลับหน้าแผนที่หลัก ไปหน้าจุดบริการ (Data)

กำหนดพิกัด แนวเส้นลูกศรฉาก และรูปภาพขั้นตอน (ชีท way)

ลากย้ายกล่องจุดบริการ หรือ ลากปุ่มสีส้มกลางเส้นลูกศรแนวฉาก เพื่อขยับหลบไม่ให้เส้นลูกศรทับกัน (กดปุ่ม เพื่อสลับแนวฉาก H/V)

สามารถเพิ่มคำอธิบาย Description และลิงก์รูปภาพ ImageURL จาก Google Drive ได้ในตารางด้านล่าง
รายการขั้นตอน Description รูปภาพ และแนวเส้นลูกศร (ชีท way)
สามารถปรับรูปแบบแนวฉาก (H = แนวนอนก่อน, V = แนวตั้งก่อน) และระยะเลื่อนเส้น (%) ได้ทั้งบนแผนผังและในตาราง
ลำดับ ชื่อขั้นตอน (B) Description (C) ImageURL (D) ภาพตัวอย่าง ปรับเส้นลูกศรถัดไป พิกัด (Top,Left) กลุ่มงาน (J) แสดง ลบ
